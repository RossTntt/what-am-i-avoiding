# what-am-i-avoiding

一个纯静态的拖延觉察工作台，用来快速回答“我现在在逃避什么？”并把答案接到一个两分钟以内的小动作上。

## 使用方式

直接打开 `index.html`，或把仓库作为静态站点部署即可。项目没有构建步骤，也不依赖本地运行环境。

页面主要交互：

- 在第一栏搜索并选择一个逃避原因大方向。
- 在第二栏选择这个大方向下的具体原因分类。
- 在第三栏选择最接近的完整表述和一个下一步小动作。
- 点击“确认填入”后，屏幕中间显示一张完整的觉察结果卡片。
- 点击“复制结果”得到同一份完整结果。

## 内容维护

所有大方向和分类内容都在 `assets/avoidance-categories.js` 里维护。

`window.AVOIDANCE_GROUPS` 维护第一层大方向：

- `id`：稳定标识，使用英文短横线命名。
- `title`：大方向标题。
- `icon`：大方向图标。
- `tone`：大方向强调色。
- `description`：大方向说明。
- `categoryIds`：这个大方向下包含的分类 `id`。

`window.AVOIDANCE_CATEGORIES` 维护具体原因分类。每个分类包含：

- `id`：稳定标识，使用英文短横线命名。
- `title`：分类标题。
- `icon`：分类图标。
- `tone`：分类强调色。
- `description`：分类说明。
- `typical`：左侧和详情区展示的典型表现。
- `options`：可选择的完整逃避表述。
- `actions`：可以接上的小动作。

新增或调整分类时，优先保持每个分类都有至少 3 个 `typical`、多个 `options` 和 2 到 4 个 `actions`。

## 设计约定

- 桌面端按三段式工作台设计，依次显示大方向、具体原因、句子与行动。
- 移动端改为单列布局，允许自然向下浏览。
- 顶部只展示状态提示；逐层选择过程中的结果先显示为待确认预览。
- 确认后的完整结果只会在工作区上方居中展示，继续选择时保留上一次确认结果。
- 完整结果以觉察卡片呈现，包含解释性标题、大方向说明、具体原因说明、具体逃避表述和下一步行动。
- 不引入框架、构建工具或第三方依赖。
- 不保留旧文件名兼容入口；当前入口是 `index.html`。

## 打印

浏览器打印时会隐藏搜索和复制操作，按大方向展示全部分类、完整选项和小动作，适合输出为简洁清单。
