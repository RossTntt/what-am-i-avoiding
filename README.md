# what-am-i-avoiding

一个纯静态的拖延觉察工作台，用来快速回答“我现在在逃避什么？”并把答案接到一个两分钟以内的小动作上。

## 使用方式

直接打开 `index.html`，或把仓库作为静态站点部署即可。项目没有构建步骤，也不依赖本地运行环境。

页面主要交互：

- 在左侧搜索分类、关键词或完整选项。
- 选择一个逃避原因分类。
- 在右侧选择最接近的完整表述。
- 选择一个下一步小动作。
- 点击“复制填空句”得到完整句子。

## 内容维护

所有分类内容都在 `assets/avoidance-categories.js` 里维护。

每个分类包含：

- `id`：稳定标识，使用英文短横线命名。
- `title`：分类标题。
- `icon`：分类图标。
- `tone`：分类强调色。
- `description`：分类说明。
- `typical`：左侧和详情区展示的典型表现。
- `options`：可选择的完整逃避表述。
- `actions`：可以接上的小动作。

新增或调整分类时，优先保持每个分类都有至少 3 个 `typical`、多个 `options` 和 2 到 4 个 `actions`。

## 设计约定

- 桌面端按一屏工作台设计，页面本身不纵向滚动；左侧分类和右侧选项在各自区域内滚动。
- 移动端改为单列布局，允许自然向下浏览。
- 不引入框架、构建工具或第三方依赖。
- 不保留旧文件名兼容入口；当前入口是 `index.html`。

## 打印

浏览器打印时会隐藏搜索和复制操作，展示全部分类、完整选项和小动作，适合输出为简洁清单。
