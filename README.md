# what-am-i-avoiding

一个纯静态的拖延觉察工作台，用来快速回答“我现在在逃避什么？”并把答案接到一个两分钟以内的小动作上。

## 基本方法论

这个项目把拖延视为一个信号，而不是一个性格问题。它不试图诊断用户，也不要求用户一次想清楚全部原因，而是帮助用户把“我不想开始”的模糊状态，压缩成一个更具体、更可行动的卡点。

核心路径是：

1. 先从当下感觉进入。用户通常不是先知道原因，而是先感到“怕”“累”“不知道怎么开始”“只想舒服一下”。快速状态入口用于降低第一步判断成本。
2. 再定位可能的卡点。大方向和具体原因只是辅助分类，结果应被理解为“我现在可能卡在这里”，而不是绝对结论。
3. 用完整句子替代模糊内耗。用户选择一句最像自己的表述，把脑子里的混乱变成可看见、可复制、可继续处理的一句话。
4. 下一步只恢复接触，不要求完成任务。小动作必须能在 2 分钟内开始，且无需继续拆解；它的目标是重新接上任务，而不是一次解决任务。
5. 允许不完美版本。很多拖延来自“还没想清楚所以不能开始”，因此工具默认鼓励先做粗糙入口、占位版本、v0 骨架或最小交付。
6. 保留选择权。推荐动作优先给出低成本路径；通用动作库和自定义输入用于覆盖具体工作场景，避免用户因为没有合适选项而再次卡住。

最终产物不是待办事项，而是一张觉察卡片：我可能在逃避什么、具体卡在哪里、我接下来只做哪一个小动作。

## 使用方式

直接打开 `index.html`，或把仓库作为静态站点部署即可。项目没有构建步骤，也不依赖本地运行环境。

页面主要交互：

- 先点一个最像当下状态的快速入口，缩小可选范围；也可以直接查看全部分类。
- 在第一栏搜索并选择一个逃避原因大方向。
- 在第二栏选择这个大方向下的具体原因分类。
- 在第三栏选择最接近的完整表述和一个下一步小动作；如果推荐动作不合适，可以展开通用动作库或自己写一个小动作。
- 点击“确认填入”后，屏幕中间显示一张完整的觉察结果卡片。
- 点击“复制结果”得到同一份完整结果。

## 内容维护

所有大方向和分类内容都在 `assets/avoidance-categories.js` 里维护。

`window.AVOIDANCE_GROUPS` 维护第一层大方向：

- `id`：稳定标识，使用英文短横线命名。
- `title`：大方向标题。
- `icon`：大方向图标。
- `tone`：大方向强调色。
- `description`：大方向说明。
- `categoryIds`：这个大方向下包含的分类 `id`。

`window.AVOIDANCE_QUICK_STATES` 维护快速状态入口：

- `id`：稳定标识，使用英文短横线命名。
- `label`：入口按钮文案。
- `description`：入口说明。
- `tone`：入口强调色。
- `categoryIds`：点击入口后优先展示的分类 `id`。

`window.AVOIDANCE_CATEGORIES` 维护具体原因分类。每个分类包含：

- `id`：稳定标识，使用英文短横线命名。
- `title`：分类标题。
- `icon`：分类图标。
- `tone`：分类强调色。
- `description`：分类说明。
- `typical`：左侧和详情区展示的典型表现。
- `options`：可选择的完整逃避表述。
- `actions`：当前分类下优先展示的推荐小动作。

`window.AVOIDANCE_ACTION_LIBRARY` 维护通用动作库。每个动作组包含：

- `id`：稳定标识，使用英文短横线命名。
- `title`：动作组标题。
- `description`：动作组适用说明。
- `actions`：这一组里可直接选择的小动作。

新增或调整分类时，优先保持每个分类都有至少 3 个 `typical`、多个 `options` 和至少 3 个推荐 `actions`。所有动作都应该是 2 分钟内能立刻执行、无需继续拆解的具体动作。

## 设计约定

- 桌面端按三段式工作台设计，依次显示大方向、具体原因、句子与行动。
- 快速状态入口只负责筛选下方三段式工作台，不替代完整分类浏览。
- 下一步小动作默认展示当前分类推荐动作；通用动作库和自定义输入通过“更多小动作”浮层面板展开。
- 移动端改为单列布局，允许自然向下浏览。
- 顶部只展示状态提示；逐层选择过程中的结果先显示为待确认预览。
- 确认后的完整结果只会在工作区上方居中展示，继续选择时保留上一次确认结果。
- 完整结果以觉察卡片呈现，包含解释性标题、大方向说明、具体原因说明、具体逃避表述和下一步行动。
- 不引入框架、构建工具或第三方依赖。
- 不保留旧文件名兼容入口；当前入口是 `index.html`。

## 打印

浏览器打印时会隐藏搜索和复制操作，按大方向展示全部分类、完整选项和小动作，适合输出为简洁清单。
